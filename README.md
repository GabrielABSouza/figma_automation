# figma_automation

> AI-powered Figma automation: turns a product intent into structured UI screens, rendered in Figma. Orchestrated with LangGraph and Google Gemini.

## What it does

Takes a product intent and produces structured UI designs through an agent pipeline (LangGraph), generating layouts with Google Gemini and rendering them into Figma via a FastAPI backend.

## Stack

Python · FastAPI · LangGraph · LangChain · Google Gemini · Pydantic.

## Status

Prototype / work in progress.
